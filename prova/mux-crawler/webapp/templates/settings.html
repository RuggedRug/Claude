Configuration File

Edit the .env file to change configuration: 

# Mux Configuration
MUX_ORG_ID=your_org_id
MUX_ENV_ID=your_env_id
MUX_USER_ID=optional_user_id

# Database
DATABASE_URL=postgres://...

# Extraction
EXTRACTION_START_DATE=2024-10-01
Help
Finding your Mux IDs

Your organization and environment IDs can be found in the Mux dashboard URL:

dashboard.mux.com/organizations/ORG_ID/environments/ENV_ID/views
Re-authenticating

1. Click "Clear Authentication" above
2. Go to Dashboard and click "Run Headed"
3. Log in to Mux in the browser window
4. Wait for redirect to complete
